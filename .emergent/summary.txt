<product_requirements>
The project is ProCreators, an AI-powered SaaS platform for social media content. The primary goal is to provide a robust **Story Video Reels** feature.

**Core Workflow:**
A user provides a script, and the system automatically generates a short video (10-60 seconds). The process involves:
1.  Extracting thematic English keywords from the script using an AI model (Gemini).
2.  Fetching relevant stock video clips from Pexels.
3.  Generating a voiceover for the script using a Text-to-Speech (TTS) service. The user should be able to select from available providers.
4.  Compositing the video clips, voiceover, and dynamic captions into a final MP4 file.

**Implementation So Far:**
The feature has been built but required extensive debugging. The current implementation successfully concatenates multiple Pexels clips and uses the user's paid ElevenLabs subscription for high-quality TTS. Memory optimization (video streaming) and environment stability documentation (for FFmpeg) have been put in place. The immediate goal is to ensure this stabilized version works reliably for the user.
</product_requirements>
