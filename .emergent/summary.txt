<product_requirements>
The project is ProCreators, an AI-powered SaaS platform designed to help content creators generate a variety of social media assets.

**Core Features Implemented:**
*   **AI Content Tools:** Generators for Threads, Quotes, News, Lists, Photo Cards, and Carousels.
*   **Automatic Content Library:** All generated content is automatically saved to a MongoDB-backed library with a tier-based expiration policy. Manual save buttons have been removed.
*   **Viral Content Enhancement:** System prompts have been engineered to include viral hooks at the beginning of generated text content to increase engagement.
*   **Advanced Reels/Shorts Creator:** A sophisticated tool for generating vertical videos.
    *   **Multi-Input System:** Accepts a text topic, a main character/object image, and an optional talking head image, with smart logic to create scripts based on the provided inputs.
    *   **Multi-Model Backend:** Uses Replicate to intelligently select from various video generation models (e.g., SVD, Luma) based on user-selected quality modes (Budget, Pro), abstracting the underlying model from the user.
    *   **Platform-Specific Aspect Ratios:** Allows users to select a target platform (TikTok, YouTube Shorts, Instagram Reels) to generate videos in the correct 9:16 vertical format.
    *   **Basic Editing:** UI for trimming and applying filters.
    *   **UI/UX:** Features a video preview, download button, and a progress bar during generation.
*   **Theming:** Supports both light and dark modes across the entire application, including public-facing pages and the user dashboard.
</product_requirements>
