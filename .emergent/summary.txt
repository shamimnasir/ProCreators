<product_requirements>
The project is ProCreators, an AI-powered SaaS platform for content creators. The primary goal is to provide a suite of tools for generating multi-format content (text, image, carousels) with support for English and Bengali.

**Core features implemented:**
*   **AI Tools:** Generators for Threads, Quotes, News, Lists, Tutorials, Photo Cards, and multi-slide Carousels.
*   **Content Sourcing:** Tools can generate content from a simple prompt or from the context of a provided URL.
*   **Advanced Photo Card Editor:** A highly-customizable tool for creating viral social media cards with image/logo uploads, text overlays, color pickers, and live-preview image filters.
*   **Advanced Carousel Generator:** A multi-step tool that can auto-generate a 5-slide content plan, create slides manually or automatically, and add a brand logo.
*   **Content Library:** A MongoDB-backed section where all generated content is automatically saved. Content has a time-based expiration (7 days for free users, 3 months for paid), and expired content is hidden.
*   **Admin System Prompts:** A feature for admins to configure the default AI instructions for each tool.
*   **Public Pages:** A full homepage and placeholder pages for Roadmap, Blog, and Docs have been created with a consistent layout and navigation.
</product_requirements>
