## Quick Start Guide

### Step 1: Create a New Page
1. Open Notion and create a new page
2. Add an icon: 💼
3. Add a cover image (gradient or photo)
4. Title it: "CRM & Sales Dashboard"

### Step 2: Understand the System

Welcome to your Sales CRM! This system helps you track every lead from first touch to closed deal.

1. **Add companies** - Enter your target accounts and prospects

2. **Add contacts** - Log key people at each company with roles and notes

3. **Create deals** - Track opportunities through your sales pipeline

4. **Log activities** - Record all calls, emails, and meetings

5. **Follow up** - Use Next Action dates to never miss a follow-up

## Databases to Create (4)

Create each database as an **inline database** on your main page.

### Database 1: 💰 Deals Pipeline

**Purpose:** Track all sales opportunities

**How to create:**
1. Type `/database` and select "Database - Inline"
2. Name it "Deals Pipeline"
3. Add the properties below

**Properties to add:**

| # | Property Name | Type | How to Set Up |
|---|--------------|------|---------------|
| 1 | 💼 Deal | title | Already exists as "Name" - rename it |
| 2 | 📊 Stage | select | Add options: Lead, Qualified, Proposal Sent... |
| 3 | 💰 Value | number | Number format (or currency if money) |
| 4 | 📈 Probability | number | Number format (or currency if money) |
| 5 | 📅 Expected Close | date | Date property |
| 6 | 🏢 Company | relation | Relation to another database |
| 7 | 👤 Contact | relation | Relation to another database |
| 8 | 👔 Owner | person | Person property |
| 9 | 📥 Source | select | Add options: Inbound, Outbound, Referral... |
| 10 | ➡️ Next Action | text | text property |
| 11 | ⏰ Next Action Date | date | Date property |

**Select/Multi-select Options:**

- **Stage**: Lead, Qualified, Proposal Sent, Negotiation, Closed Won, Closed Lost
- **Source**: Inbound, Outbound, Referral, Partner, Event, Website

## Pro Tips

**Make it look professional:**
- Add a gradient cover image (Unsplash has great free ones)

- Create a "Quick Actions" section with buttons using callout blocks
- Use dividers and headings to organize sections
- Add a toggle for the "Getting Started" guide

**Improve functionality:**
- Set up Relations between databases (e.g., Deals -> Companies)
- Create Rollup properties to show related data
- Use Formula properties for calculations
- Create filtered views for "My Items" or "This Week"
- Pin your most-used views
